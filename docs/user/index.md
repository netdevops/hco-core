# User documentation

This part is for the person who requests and approves changes.

1. [Concepts](concepts.md): runs, run states, risk tiers, and approvals.
2. [The command line](cli.md): the `hco-core` command.
3. [The REST API](api.md): the routes, the errors, and examples with `curl`.

hco-core does not write to a device in Phase 1. A run stops when it is approved.
