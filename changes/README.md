# Changelog fragments

- Name each fragment `<issue>.<type>`, for example `1.added`. Use the pull request number when no issue exists.
- Use one of these types: `added`, `changed`, `fixed`, `removed`, `security`, `dependencies`, `documentation`.
- Write one item on each line. Do not add a bullet marker. The template `changes/_template.md` gives each line its own bullet and issue link.
- Write a maximum of three items in each fragment.
